# آموزشگاه فناوری | IT Academy

سایت آموزشگاه IT، خواهرِ [مجله IT](https://github.com/AAli-gh/IT-magazine) و هم‌معماری با آن:

**استک:** Python · Django 5.2 · Django REST Framework · PostgreSQL · Redis · Tailwind CSS · HTMX · django-allauth (+2FA)

## امکانات
- دوره‌ها با دسته‌بندی، سطح، شهریه، سرفصل، مدرس و **دوره‌های برگزاری** (تاریخ، ظرفیت، حضوری/آنلاین)
- ثبت‌نام و مشاوره با HTMX (honeypot، محدودیت نرخ، اعتبارسنجی موبایل، ظرفیت)، مدیریت در پنل ادمین
- جستجو و فیلتر (با پیشنهاد زنده)، صفحه مدرسان، سؤالات متداول، فرم تماس، نظرات و امتیاز دانشجویان
- **پنل دانشجو** (`/panel/`): داشبورد، دوره‌های من با نوار پیشرفت، درس‌ها (ویدئو، متن، فایل ضمیمه خصوصی)، علامت‌گذاری درس انجام‌شده، برنامه کلاس‌ها، اطلاعیه‌ها (عمومی یا مخصوص یک دوره برگزاری)، ثبت‌نام‌ها با امکان لغو. محتوا فقط برای دانشجوی **تأییدشده** باز است؛ فایل‌ها خارج از `MEDIA_ROOT` (پوشه `private_media/`، قابل تغییر با `PRIVATE_MEDIA_ROOT`) نگه‌داری و فقط پس از بررسی دسترسی ارسال می‌شوند.
- **آزمون** چندگزینه‌ای (درصد قبولی، زمان‌سنج با ارسال خودکار، سقف دفعات، تصحیح سمت سرور؛ کلید پاسخ هرگز به مرورگر ارسال نمی‌شود)
- **تکلیف** با متن/فایل خصوصی، مهلت، نمره و بازخورد مدرس (نمره‌دهی از ادمین؛ دانشجو ایمیل می‌گیرد)
- **گواهی پایان دوره:** پس از انجام همهٔ درس‌ها، قبولی در آزمون‌ها و تکالیف، صادر می‌شود؛ کد یکتا (`ITA-…`)، صفحهٔ عمومی اعتبارسنجی `/certificates/<code>/`، چاپ/ذخیره PDF از مرورگر، و امکان ابطال از ادمین
- **پنل مدرس** (`/teach/`): مدرس فقط دوره‌های خودش را می‌بیند و مدیریت می‌کند: درس‌ها (متن، ویدئوی آپلودی یا لینک، فایل)، اطلاعیه، تکلیف و نمره‌دهی (با اعلان به دانشجو)، جلسات و **حضور و غیاب**، فهرست دانشجویان با پیشرفت/حضور/میانگین نمره و کارنامهٔ هر نفر. آزمون‌ها و تنظیمات دوره (شهریه، انتشار) همچنان از ادمین انجام می‌شود.
- **کارنامه** برای دانشجو (`/panel/courses/<دوره>/report/`): پیشرفت درس‌ها، نتایج آزمون و تکلیف، درصد حضور و شرایط گواهی. جلسهٔ گذشتهٔ ثبت‌نشده «غایب» حساب می‌شود و غیبت موجه به ضرر دانشجو نیست.
- **ویدئوی آپلودی** (mp4/webm، سقف `MAX_VIDEO_UPLOAD_MB`): خارج از پوشهٔ عمومی ذخیره و فقط برای دانشجوی تأییدشده/مدرس همان دوره با پشتیبانی Range (جلو/عقب‌بردن) پخش می‌شود. دکمهٔ دانلود پخش‌کننده و منوی راست‌کلیک غیرفعال است، ولی این فقط مانع کاربر عادی است؛ جلوگیری کامل از ضبط/دانلود هر ویدئویی که در مرورگر پخش شود ممکن نیست (برای آن به DRM/سرویس ویدئوی تخصصی نیاز است).
- **لیست انتظار:** وقتی ظرفیت یک دوره برگزاری پر است، فرم ثبت‌نام آدم را در لیست انتظار می‌گذارد. با لغو یک ثبت‌نام یا افزایش ظرفیت، نفر بعدی اطلاع می‌گیرد و ۴۸ ساعت جا برایش نگه داشته می‌شود (بعد از آن نوبت به نفر بعدی می‌رسد).
- **اعلان‌ها** (زنگوله و `/panel/notifications/`، خوانده/نخوانده + ایمیل در صورت فعال بودن): تأیید ثبت‌نام، اطلاعیه، نمره، گواهی، جای خالی، تحویل جدید برای مدرس. دانشجو می‌تواند ایمیل اعلان‌ها را در پروفایل خاموش کند.
- **یادآوری‌ها:** `python manage.py send_reminders` را روزانه اجرا کنید (cron یا Scheduled Task پایتون‌اني‌ور). کلاس‌های ۲۴ ساعت آینده و تکالیف نزدیک به مهلت را یادآوری می‌کند؛ تکرار نمی‌فرستد.
- **گزارش مدیر** (`/manage/reports/`، فقط مدیر یا کارمند با مجوز مشاهدهٔ ثبت‌نام): ثبت‌نام‌های جدید، روند، دانشجو، درآمد (شهریه، دریافتی و مانده بر اساس «مبلغ پرداخت‌شده» که در ثبت‌نام‌ها دستی وارد می‌شود)، پرکاربردترین دوره‌ها، نرخ تکمیل (گواهی ÷ تأییدشده) و امتیاز.
- **سئو:** داده ساختاریافته JSON-LD (Course با قیمت به ریال، دوره‌های برگزاری، امتیاز؛ WebSite با SearchAction؛ Organization؛ BreadcrumbList) و Open Graph برای هر دوره.
- **جستجوی فارسی:** یکسان‌سازی ی/ک و ارقام و نیم‌فاصله، مترادف فارسی/انگلیسی (پایتون ⇄ python)، همهٔ کلمات باید بیایند، و اصلاح غلط تایپی ساده («pyton») وقتی چیزی پیدا نشود.
- ایمیل به آموزشگاه و دانشجو هنگام ثبت‌نام، و ایمیل تأیید وقتی ادمین ثبت‌نام را تأیید می‌کند
- **اتصال به مجله:** مطالب مرتبط هر دوره، آخرین مطالب مجله، و API دوره‌ها برای مجله (جزئیات: [docs/MAGAZINE_INTEGRATION.md](docs/MAGAZINE_INTEGRATION.md))
- API: `/api/courses/` (فیلتر `q`, `category`, `level`, `tag`)، `/api/categories/`
- SEO (sitemap، robots، OG)، تم تیره/روشن، پنل ادمین با 2FA، صفحات خطای اختصاصی، Sentry، Docker، CI

## راه‌اندازی (توسعه)
```bash
python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
npm ci && npm run build          # Tailwind + فونت/HTMX محلی (خروجی در static/ کامیت می‌شود)
python manage.py migrate
python manage.py seed_school --demo
python manage.py createsuperuser
MAGAZINE_URL=http://localhost:8000 python manage.py runserver 8001
```
یا `docker compose up` (آموزشگاه روی پورت 8001، مجله روی 8000).

تست: `python manage.py test` — تنظیمات: `.env.example`.
