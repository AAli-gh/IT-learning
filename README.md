# IT-learning — سایت آموزشگاه IT

سایت استاتیک فارسی (RTL) بدون نیاز به build. فقط پوشه را روی هر هاست بگذارید.
برای اجرای محلی: `python3 -m http.server` و باز کردن `http://localhost:8000`.

## ساختار
- `index.html` صفحه اصلی، `courses.html` لیست دوره‌ها، `course.html?id=...` جزئیات دوره
- `data/courses.json` اطلاعات دوره‌ها (برای افزودن دوره فقط همین فایل را ویرایش کنید)
- `js/config.js` تنظیمات اتصال به مجله

## اتصال به مجله
1. در `js/config.js` مقدار `magazine.url`، `feedUrl` و `tagUrl` را با آدرس واقعی مجله پر کنید.
2. هر دوره یک `magazineTag` دارد؛ صفحه دوره مطالب مرتبط را از مجله نشان می‌دهد و به صفحه برچسب آن لینک می‌دهد.
3. صفحه اصلی آخرین مطالب مجله را نمایش می‌دهد (اگر feed در دسترس نباشد، مطالب نمونه).
4. جهت برعکس: مجله می‌تواند `https://YOUR-SCHOOL/data/courses.json` را بخواند و زیر هر مطلب، دوره مرتبط (با همان `magazineTag`) را پیشنهاد دهد. اگر مجله دامنه جدا دارد، CORS را برای این فایل باز کنید.
